NOVA Voice Assistant: Phone Command Guide

Purpose: Speak a command in Termux and NOVA routes it to a local handler. Known phone actions work without Groq. Groq is only used for open-ended questions or commands NOVA does not recognize.

Basic setup: Install Termux:API and run pkg install termux-api. Give Termux microphone permission. Install Shizuku and configure rish only for privileged Android settings.
Safety: Calls, SMS, shell commands, reboot, app removal, and settings changes can have real effects. Check the text NOVA recognized before using destructive actions.

Start and Help

  • help - Show commands
  • history - Show recent actions
  • exit or quit - Stop NOVA
  • ask <question> - Ask Groq

Phone Controls

  • wifi on / wifi off - Wi-Fi
  • bluetooth on / bluetooth off - Bluetooth
  • brightness 0-255 - Screen brightness
  • battery - Battery status
  • flashlight on / flashlight off - Torch
  • mobile data on/off - Requires Shizuku
  • airplane mode on/off - Requires Shizuku
  • volume 0-100 - Media volume, usually requires Shizuku
  • screen timeout <seconds>
  • rotation lock on/off
  • dnd on/off - Do Not Disturb
  • screenshot
  • tap <x> <y> - Tap screen coordinates through Shizuku
  • lock screen
  • reboot - Destructive; confirmation is enabled by default

Semantic UI Control

These commands inspect the visible Android UI and act on matching text. They require Shizuku and rish.

  • click <visible text>
  • click text <visible text>
  • press <visible text>
  • select <visible text>
  • long press <visible text>
  • type <text> into the focused field
  • press key enter|escape|backspace
  • volume up / volume down
  • play, pause, next track, previous track
  • go back, go home, recent apps
  • scroll up, scroll down
  • swipe left, swipe right
  • open quick settings, open internet
  • open volume, open brightness
  • open notifications, open power menu
  • allow, continue, confirm, approve, done, enable - safe prompt labels only

Requirements

  • Works locally: time, date, calculations, notes, tasks, file tools, parser commands.
  • Termux:API: SMS, calls, battery, torch, screenshots, notifications, clipboard, microphone, notifications.
  • Shizuku/rish: mobile data, airplane mode, volume, screen timeout, rotation, DND, privileged app controls.
  • Internet: Groq, weather, news, search, currency, translation.
  • Other apps: WhatsApp, Telegram, music, podcasts, smart-home controls require their apps or integrations.
